Le badge nomme un statut ou un rôle en un mot. Choisissez le ton selon le sens : `success` pour Actif ou Payée, `warning` pour En attente, `danger` pour En retard ou Annulée, `info` pour Système ou Brouillon, `brand` pour un rôle, `neutral` pour le reste.

Le consommateur fournit toujours un mot : la couleur ne porte jamais seule le sens, pour rester lisible par les personnes daltoniennes. Ajoutez `dot` quand le statut évolue dans le temps. Un badge n'est pas cliquable.
