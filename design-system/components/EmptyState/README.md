L'état vide remplace une liste sans élément ou un filtre sans résultat. Il explique pourquoi la zone est vide et propose le prochain pas.

Le consommateur fournit `title`, `description` et, si une action existe, un bouton `action`. Écrivez "Aucune donnée" avec la phrase "Les éléments ajoutés apparaîtront ici. Si un filtre est actif, essayez de le modifier." pour une liste filtrable, et un titre propre à l'écran ailleurs ("Aucune activité à venir"). L'icône reflète l'objet (`calendar`, `users`, `receipt`), `search` par défaut.
